# 🌳 Sharma Family Tree — Rooted in Love

An illustrated, interactive family tree application crafted with love to celebrate and explore our generations from Nana and Nani to every branch and star in our family.

## ✨ Features

- **Illustrated Scenery**: Handcrafted botanical and garden visuals featuring our family tree.
- **Interactive Branches**: Expand, collapse, and explore couples and children across generations.
- **Search & Focus**: Instant search for any family member with auto-scrolling to their branch.
- **Photo Memories**: View and customize family portraits in the gallery.
- **Add Family Members**: Easily add new children and branches to keep our family story growing.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or bun

### Installation

```sh
npm install
```

### Running Locally

```sh
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or the port displayed in your terminal) in your browser.

### Building for Production

```sh
npm run build
```

## 🛠️ Tech Stack

- **Framework**: TanStack Start & React 19
- **Routing**: TanStack Router (File-based routing)
- **Styling**: Tailwind CSS & Lucide Icons
- **UI Components**: Radix UI primitives
